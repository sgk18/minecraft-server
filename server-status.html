Azure Container Power Actions

Start, stop (pause billing when nobody is playing), or restart your container instance.

Vercel Environment Variables Configuration

In your Vercel Dashboard → Project Settings → Environment Variables, add these variables: 

MINECRAFT_SERVER_HOST=minesvrbedrock.southcentralus.azurecontainer.io
MINECRAFT_SERVER_PORT=19132
SERVER_NAME=Azure Bedrock Realm
AZURE_REGION=southcentralus
AZURE_RESOURCE_GROUP=mineResGroup
AZURE_CONTAINER_NAME=minecotainer
AZURE_STORAGE_ACCOUNT=acismineacc
AZURE_STORAGE_SHARE=acismineshare

Azure CLI Container Management Commands

Start Server (Resume Game)
az container start -g mineResGroup -n minecotainer
Stop Server (Save Azure Billing)
az container stop -g mineResGroup -n minecotainer
Stream Container Logs
az container logs -g mineResGroup -n minecotainer --follow
